ATLAS 本地数据目录
==================

每个身份码对应这里的一个文件夹，文件夹名就是身份码（统一小写）：

  data/
    alice/
      identity.json          身份元数据（创建时间 / 最近登录时间）
      untitled1.json         一个产品一份 JSON
      云台方案A.json
    .handoff/                进入下一阶段时的临时交接文件（12 小时后过期）

说明
----
1. 产品 JSON 就是页面交给下一阶段（next.html）的同一份内容，另外多了四个字段：
   projectName（产品名）、savedAt（保存时间）、savedBy（身份码）、storage（文件名）。
2. 「进入下一阶段」的临时交接文件放在 data/.handoff/，12 小时后自动过期，可随时清空。
3. 可以直接复制、备份、改名这些 .json 文件；页面「我的」里的历史列表来自本目录扫描。
4. 删除某个身份码文件夹 = 删除该身份和它的全部产品，不可恢复。
5. 想换存放位置：启动前设置环境变量 ATLAS_DATA_DIR（例如 D:\atlas-data），见 README。
6. 身份码的"登录/创建"只做目录检查，没有密码；这是本地单机工具，不是账号系统。
